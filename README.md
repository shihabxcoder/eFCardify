## 📖 About

**eFCardify** is an Android app for eFootball fans to create professional player cards easily. Simple, fast, and packed with features!

## ✨ Features

- 🎨 **4 Card Templates** - Epic, Old Epic, POTW, Show Time
- 🖼️ **Image Control** - Upload, drag, resize (50%-200%)
- ✏️ **Quick Editing** - Tap to edit name, rating, position
- 🏴 **15+ Country Flags** - Searchable flag library
- 📁 **Custom Club Logos** - Upload from gallery
- 🎯 **Eraser Tool** - Remove backgrounds with undo/redo
- 💾 **HD Export** - Save to gallery automatically
- 🌙 **Dark Mode** - Easy on the eyes

## 🎮 How to Use

1. **Choose Template** - Pick Epic, Old Epic, POTW or Show Time
2. **Add Images** - Upload player photos, drag to position
3. **Edit Text** - Tap name/rating/position to edit
4. **Add Logo** - Select country flag or upload club logo
5. **Erase (Optional)** - Clean up backgrounds if needed
6. **Save** - Tap download, find in Gallery → eFCardify

**Tip:** Images max 5MB, supports PNG/JPG
